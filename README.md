# HSdeck The Witchwood 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## API 경량화 및 편집 지침 (2026-11-14)

- 공개 카드/시각 자료는 `cards.json` 현재 목록, `data/<CARD_ID>.json` 날짜별 카드 스펙, `art/`, `golden/` 일반·황금 카드 원화/애니메이션, `frame/` 프레임·셰이더·텍스처입니다. 과거 원본과 토큰/자식 카드 연결을 보존합니다.
- 루트 `render.json`, `history.json`, `*-date.json`은 중복 호환 집계물이므로 더는 저장소에 커밋하지 않습니다. 검증 중 빌더가 생성할 수 있지만 Git에서 제외합니다. 불필요한 schema/legacy 래퍼를 새로 작성하지 않습니다.
- 카드별 최초 실제 사용 가능일은 한국 날짜로 기록합니다. 베타 북미 시각은 KST 변환, 모험은 실제 지구 개방, 이벤트는 실제 개시일, 토큰은 생성 조건에 맞춰 검증합니다. 사전 클라이언트 탑재는 출시가 아니며 잘못된 이전 키는 삭제·통합합니다.
- 날짜 키 첫 기록에는 최초 카드 상태, 후속에는 달라진 필드만 입력합니다. 표시용 개행은 `<br></br>`, 원시 XML과 프레임/황금 애니메이션 바이너리는 그대로 보존합니다. 근거가 부족한 값은 검증 완료로 올리지 않습니다.
- `sources/`, `tools/`, `tests/`, `.github/` 원본 검증/재빌드 의존성을 먼저 확인한 뒤 불필요한 것만 정리합니다.


## 날짜형 단일 API 정본 (2026-11-14)

`data/<CARD_ID>.json`을 한국 날짜별 카드 상태와 변경 필드만 담는 공개 정본으로 통일합니다. 기존 `schemaVersion`, `card`, `initialSpec`, `current`, `observations`, `_meta` 등 보조 구조는 [과거 검증 보관 브랜치](https://github.com/qxwd565/The-Witchwood/tree/archive/pre-dates-v1-20261114)에 원형 보존합니다. 원화·황금 애니메이션·프레임의 원본 파일은 수정하지 않고, 카드 ID와 한국 최초 사용 가능일이 같은지 비교합니다.
